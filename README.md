## 🚀 Project Overview
This project focuses on transforming raw bookstore sales data into actionable business insights through a clean, modern, and interactive Excel dashboard. It helps stakeholders monitor financial performance, evaluate branch and channel productivity, and analyze tax (GST) collections dynamically.

---

## 📊 Key Features & KPIs
- *Top-Level KPI Cards:* Displays core metrics including Total Net Revenue ($13.1M), Total GST Collected ($691k), Total Transactions ($429k), and Average Order Value ($30.6).
- *Branch Performance:* Analyzes revenue and GST distribution across different bookstore branches.
- *Channel Analysis:* Compares sales performance between In-Store and Online channels using bar charts and a dynamic donut chart.
- *Trend Analysis:* Visualizes monthly and yearly revenue trends to identify seasonal patterns and business growth.
- *Interactive Slicers:* Allows users to filter data dynamically by year, channel, and store ID for a customized view.

---

## 🛠️ Tools & Technologies Used
- *Microsoft Excel:* Data cleaning, Pivot Tables, Pivot Charts, Custom Number Formatting, and Dashboard Design.
- *Data Visualization:* KPI cards, bar charts, donut charts, and trend line charts.

## 📂 Project Structure
- bookstore_sales.xlsx: The main Excel file containing the raw data, pivot tables, and the interactive dashboard.

## 💡 How to Use
1. Download the bookstore_sales.xlsx file from this repository.
2. Open it in Microsoft Excel (ensure macros or content are enabled if prompted).
3. Use the interactive slicers on the right side of the dashboard to filter and explore data dynamically.
